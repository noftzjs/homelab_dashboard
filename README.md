Local Hosting of web portal

1. Pull down the repo
2. CD into repo location
3. Install requirements `pip install -r requiremements.txt`
4. Run the streamlit script `streamlit run .\homelab.py`
5. Load an existing `devices.json` file or perform a scan (Example json file is included)
